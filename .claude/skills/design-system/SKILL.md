# Дизайн-система BlockCraft

Концепція — «тихий журнал про Minecraft»: редакційний мінімалізм (великі заголовки із засічками, багато повітря, одна головна річ на екрані) з блоковими акцентами (квадрати, рамки 1 px, піксельні іконки). Не форум, не маркетплейс, не «ігровий» неон.

Кожен екран веде гравця шляхом **знайти → взяти → поділитися**: зрозуміло, навіщо сторінка, що тут взяти під «Мою гру» і звідки це (джерело).

## Токени (`src/styles/tokens.css`)

```css
:root, [data-theme="light"] {
  --bg: #F4F1EA;          /* теплий папір */
  --surface: #FBF9F4;     /* картки, поля */
  --text: #1C1B18;
  --text-muted: #6E6A62;
  --line: #DDD8CC;        /* рамки, розділювачі */
  --accent: #4D7832;      /* зелений трави: «збережено», онлайн, фокус (≥ 4.5:1 на --bg) */
  --accent-contrast: #FFFFFF;
  --primary-bg: #1C1B18;  /* головна кнопка */
  --primary-fg: #F4F1EA;
  --danger: #B3402F;
  /* --warning — R3.4, разом із CompatStatus: бурштиновий, ≥ 4.5:1 на --bg і --surface */
  /* мітки розділів — лише в чипах */
  --tag-mods: #4F7A34; --tag-packs: #7E57A8; --tag-skins: #C2803A;
  --tag-servers: #2F8FA3;
}
[data-theme="dark"] {
  --bg: #121211; --surface: #1A1A18; --text: #EDEAE3; --text-muted: #8C887F;
  --line: #2C2B28; --accent: #7FB55A; --accent-contrast: #121211;
  --primary-bg: #EDEAE3; --primary-fg: #121211; --danger: #E06A55;
  /* --warning — R3.4: світліший бурштиновий, ≥ 4.5:1 на темному --bg */
}
```

Підключення в Tailwind 4 через `@theme` (`--color-bg: var(--bg)` тощо). У компонентах — лише класи токенів (`bg-bg`, `text-muted`, `border-line`), жодних hex.

Статуси сумісності: ok — `--accent`, попередження — `--warning` (новий токен, додається разом із `CompatStatus` у R3.4), помилка — `--danger`. Колір ніколи не єдиний носій сенсу: поруч завжди текст.

## Сітка й відступи

- Контейнер `max-w-[1200px] mx-auto px-4 md:px-8`.
- Шкала відступів кратна 8 px; між секціями головної — 120–160 px, у каталогах — 64 px.
- Каталоги: сітка 2 / 3 / 4 колонки (мобільний / планшет / десктоп), проміжок 24 px.
- `border-radius: 0` скрізь, включно з аватарами й кнопками.
- Рамки 1 px `--line`. Тіней і градієнтів немає.

## Компоненти — правила

- **Button:** primary (заливка `--primary-bg`), secondary (рамка 1 px), ghost (лише текст). Висота 40 / 48 px. На екрані одна primary-кнопка.
- **Card:** квадратна обкладинка 1:1 з рамкою, під нею назва (Inter 500, 15 px) і один рядок метаданих. Іконка «Зберегти» в правому верхньому куті з'являється при наведенні (на мобільних — завжди). При наведенні обкладинка трохи збільшується (`scale 1.02`, 200 мс).
- **SaveButton:** порожній квадрат-слот → при збереженні «заповнюється» `--accent` (анімація 180 мс). Лічильник поруч опційно.
- **FilterChip:** прямокутник з рамкою; активний — заливка `--text`, текст `--bg`. Фільтри — горизонтальний рядок зі скролом на мобільних, а не бокова колонка.
- **Tabs:** капслок-мітки, активна підкреслена лінією 2 px.
- **Dialog / Sheet:** на десктопі — модалка по центру, на мобільних — шторка знизу.
- **EmptyState:** маленька ілюстрація + одна фраза + одна дія.
- **Skeleton:** прямокутники кольору `--line` з пульсацією; без спінерів на весь екран.

### Компоненти v2 (`components/ui`, з'являються в R1–R3)

- **SourceBadge:** рядок метаданих «Modrinth ↗» — muted, зовнішнє посилання на `external_url`, `rel="noopener"`. Є на кожній картці (у рядку метаданих) і сторінці контенту (під головною кнопкою).
- **GameChip:** у шапці «1.21.1 · Fabric ▾» (без вибору — «Обери свою гру ▾») → поповер: версія (з `/meta`) + лоадер чипами + «Не знаю свою версію» з короткою підказкою. Десктоп — праворуч у шапці; телефон — під шапкою на всю ширину. Для гостя теж.
- **TakeButton:** головна primary-кнопка «взяти», текст включає «Мою гру»: «Завантажити для 1.21.1 · Fabric», «Завантажити .mrpack», «Скопіювати IP», «Завантажити PNG». Коли під «Мою гру» нічого немає — secondary-кнопка «Найближча версія: 1.21.11» замість неактивної.
- **CompatStatus:** квадратний маркер 8 px + текст («Сумісно», «2 попередження», «Конфлікт»); кольори — статусні токени вище.
- **ResolutionView:** блок «Що встановити»: зверху конфлікти й попередження, далі рядки — іконка 32 px, назва, версія (mono, muted), причина («потрібен для Sodium Extra», «додано: шейдерам на Fabric потрібен Iris»), `CompatStatus`. Групи: обрані · залежності · неявні. Тексти — `features/compat/copy.ts` за кодами з API.

## Сторінки

- **Каталог:** ілюстрація розділу (≤ 160 px), H1, лічильник, рядок фільтрів, сітка, «Показати ще».
- **Каталог:** фільтри за замовчуванням — з «Моєї гри»; перемикач «усі версії» в рядку фільтрів; картка, що не пасує, має мітку «не для 1.21.1».
- **Об'єкт:** перший екран — медіа ліворуч (для скіна — 3D), праворуч H1, 2 рядки опису (українською, якщо є переклад), `TakeButton`, «Зберегти» й «В збірку / добірку», `SourceBadge`. Для мода під ним — «Що встановити» (`ResolutionView`). Далі вкладки «Опис · Версії · Відгуки · Схоже».
- **Головна:** герой («Збери свій Minecraft», рядок пояснення, `GameChip`, пошук) → «Популярне для 1.21.1 · Fabric» (8 модів) → «Готові збірки» (4) → смуга «Перевір свої моди» → `/import` → «Сервери онлайн · українською» (5 рядків) → «Скін дня» (3D) + 6 скінів → футер з «Дані: Modrinth, MineSkin, Mojang» і дисклеймером «Не є офіційним продуктом Minecraft. Не пов’язано з Mojang або Microsoft». Гість без «Моєї гри» — популярне без фільтра + м’яке запрошення обрати гру.

## 3D і анімації

- 3D — лише skinview3d для скінів; ліниве завантаження, fallback-PNG, повільне обертання, при `prefers-reduced-motion` — статичний кадр.
- Анімації — CSS-переходи; `motion` — лише якщо справді знадобиться (залежність не встановлена). Без паралаксу й повноекранних ефектів.

## Мобільна версія

- Шапка: логотип, лупа, меню; під нею — `GameChip`. Нижня панель: Головна · Пошук · Поділитися · Моє (до R7.6 замість «Поділитися» — «Зібрати» → `/packs/new`, замість «Моє» — «Обране»).
- Перевіряй кожен екран на 375 px: без горизонтального скролу, зони натискання ≥ 44 px.

## Стани

Кожен екран зі запитом має стани: завантаження (skeleton), порожньо (EmptyState), помилка (фраза + «Спробувати ще»), немає доступу (пропозиція увійти).

## Перевірка перед здачею UI

- Обидві теми, 375 px і 1440 px, навігація клавіатурою, контраст ≥ 4.5:1.
- На екрані одна головна дія (`TakeButton`), тексту — мінімум, жодних hex і тіней.
- Контент показує джерело (`SourceBadge`); гість розуміє, навіщо сторінка, що взяти й що можна опублікувати.
