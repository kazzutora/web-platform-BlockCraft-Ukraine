# Фронтенд (Next.js + TypeScript)

- App Router. Сторінки каталогів і об'єктів — Server Components з даними через `src/lib/api/server-client.ts`; інтерактив — окремі Client Components (`"use client"`) якомога нижче в дереві.
- Запити з браузера — `src/lib/api/client.ts` (openapi-fetch) + TanStack Query; ключі лише з `src/lib/query-keys.ts`. Типи — лише зі згенерованого `schema.d.ts`.
- Мутації «Зберегти», «В колекцію», «В збірку», «Оцінити» — оптимістичні: `onMutate` оновлює кеш, `onError` відкочує й показує тост.
- Форми — react-hook-form + zod; помилки з API (`fields`) мапляться на поля форми.
- Компоненти: `components/ui` — без бізнес-логіки й запитів; `features/<name>` — логіка розділу.
- Файли компонентів — `PascalCase.tsx`, хуки — `useSomething.ts`, один експорт компонента на файл.
- Тексти інтерфейсу українською, апостроф `’`; не розкидай рядки по JSX — тримай їх у `features/<name>/copy.ts` або на початку файлу.
- Зображення — `next/image`; 3D-скіни — `dynamic(() => import(...), { ssr: false })` з fallback-зображенням.
- Доступність: інтерактивне — лише `button` / `a`, видимий фокус, `aria-label` для іконок, контраст ≥ 4.5:1.
- Перед будь-якою роботою з виглядом застосовуй skill `design-system`.

## v2: знайти → взяти → поділитися

- **«Моя гра»:** Server Components читають `getGameContext()` (профіль гравця або cookie гостя `bc_game`) і передають у запити; `GameChip` у шапці на десктопі й телефоні. Фільтри каталогів за замовчуванням — з «Моєї гри», перемикач «усі версії» — `all=1` в URL. Картка, що не пасує «Моїй грі», має мітку «не для 1.21.1».
- **Взяти:** головна дія сторінки об'єкта — `TakeButton` з «Моєю грою» в тексті («Завантажити для 1.21.1 · Fabric», «Завантажити .mrpack», «Скопіювати IP», «Завантажити PNG»). Поруч — «Зберегти» і «В збірку / добірку». Одна головна дія на екран.
- **Атрибуція:** кожна картка й сторінка контенту показує джерело через `SourceBadge` («Modrinth ↗», `rel="noopener"`).
- **Сумісність:** тексти пояснень — лише `features/compat/copy.ts` за кодами з API (`no_version`, `version_mismatch`, …); статус — `CompatStatus`, дерево «що встановити» — `ResolutionView`.
- **Файли гравця не покидають браузер:** `/import` рахує SHA-1 через Web Crypto і дістає з `.mrpack` лише `modrinth.index.json`.
