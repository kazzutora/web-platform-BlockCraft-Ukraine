# Прогрес розробки

Claude Code читає цей файл на початку кожної задачі й оновлює його в кінці. Деталі задач — у `docs/tech.md`, розділ 10.

## Зараз

- **Етап:** 6 — Сервери (етапи 0–5 реалізовано; гілки `stage-00` → `stage-01` → `stage-02` → `stage-03-mods` → `stage-04-library` → `stage-05-skins` чекають push, зеленого CI і злиття в `main`)
- **Наступна задача:** 6.1
- **Гілка:** `stage-06-servers` (від `stage-05-skins`)
- **Блокери:** на машині розробника ще немає GNU Make, Node.js 24 і pnpm (див. README → «Що потрібно встановити»)

## Відомі проблеми й борг

- Swagger UI (`/api/docs/`) тягне ресурси з CDN jsdelivr (`swagger-ui-dist@latest`). Для CSP на етапі 8.6 — перейти на `drf-spectacular-sidecar` або дозволити CDN у політиці.
- `make up-local` покладається на DNS Docker Desktop для `host.docker.internal`; на Linux-хості знадобиться інший спосіб (етап 9 не зачіпає — там прод без dev-фронтенду).
- Компоненти приймають `className`, але без tailwind-merge конфліктні класи (`hidden` проти `inline-flex`) не перекривають базові — для адаптивного приховування загортай у `div`.
- Вхід через Discord і Google не перевірено з реальними ключами (немає OAuth-застосунків); автотести покривають лише список провайдерів у конфігу.
- Листи allauth — стандартні шаблони з українським перекладом allauth; власні шаблони листів — разом із правовими сторінками (етап 8).
- Список версій гри в `apps/core/game.py` і `features/game/labels.ts` статичний (дубль на фронтенді); при виході нової версії Minecraft оновити обидва або перейти на таблицю версій із Modrinth.
- `notFound()` всередині потокового `<Suspense>` (`/mods/неіснуючий`, `/u/неіснуючий`) віддає HTTP 200 зі сторінкою 404 і `noindex` — статус уже відправлено разом зі статичною оболонкою.
- Хуки pre-commit для фронтенду потребують Node.js і pnpm на хості; до їх встановлення `pre-commit install` блокуватиме коміти зі змінами у `frontend/`.
- Колекцію «за посиланням» гість із токеном може переглянути й скопіювати собі, але не зберегти в обране й не лайкнути: `resolve()` для kind `collection` бачить лише публічні, власні й спільні колекції. Якщо знадобиться — передавати `share_token` у generic-дії.
- Модерація скінів поки лише в адмінці (дії «Схвалити й опублікувати», «Відхилити» зі стандартною причиною); черга модератора, власна причина й сповіщення автору — етап 8.
- Пошук скіна за ніком працює лише для Java Edition (Mojang API); Bedrock-гравців (Xbox) не знайти.
- Закритий профіль не показує й скін; власник бачить свій профіль так само, як інші.
