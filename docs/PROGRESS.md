## Рішення v1, що лишаються в силі

Деталі й причини — `docs/archive/v1/PROGRESS.md`.

- Django 5.2 LTS; `django-environ`; DRF за замовчуванням `IsAuthenticated`, публічне — явно `AllowAny`; `ALLOWED_HOSTS` містить `backend`.
- Сесійна авторизація allauth headless на одному origin; вхід за email з підтвердженням посиланням; `GET /csrf`; неавторизований — 401; типи allauth генеруються; Discord/Google з auto-connect (з реальними ключами не перевірено).
- `User` без `username`; email і нік унікальні без урахування регістру; валідація ніка; `django.contrib.sites` з назвою «BlockCraft Ukraine».
- Єдиний формат помилок `core.exceptions.handler`; `DomainError(code, message)`; DELETE-параметри — у query string.
- Тротлінг з `NUM_PROXIES = 1`, SSR пересилає `X-Forwarded-For`.
- `.gitattributes` з `eol=lf`; Makefile сумісний з `sh` і `cmd.exe`; на Windows фронтенд — локально (`make up-local` + `pnpm dev`), Nginx бере адресу з `FRONTEND_UPSTREAM`.
- `make api-types` експортує `frontend/openapi.yaml` (комітиться) → `schema.d.ts`; CI перевіряє актуальність; енуми OpenAPI з явними назвами.
- Next.js 16: `cacheComponents`, `server-client.ts` викликає `connection()`, дані API — у `<Suspense>`; `src/proxy.ts` з cookie-підказкою `bc_signed_in`; `requireAuth` + `usePendingAction`; вміст `layout` в одному `div` (Radix `aria-hidden`).
- TypeScript 5.x (peer `openapi-typescript`).
- Tailwind 4: стандартні палітра, радіуси, тіні вимкнені, сканується лише `src/`; `radix-ui`; `pixelarticons` поштучно, власна заповнена зірка; колір розділу в `Chip` — квадратний маркер; апостроф `’`.
- ruff: RUF001–RUF003 вимкнено (кирилиця свідома).
- Клієнт Modrinth: повтори з backoff, пауза за `Retry-After`/`X-Ratelimit-Reset`; markdown → `markdown-it-py` + `nh3` під час синхронізації.
- Kinds реєструються в `AppConfig.ready()`; `resolve()` дає 404 і для неіснуючих, і для прихованих; видалення об'єкта чистить пов'язане через `kinds.on_register`; лічильники — `core.counters.bump()` з `Greatest(…, 0)`.
- Оптимістичне «Зберегти» тримає стан у компоненті (`useSave`) і після успіху інвалідовує `library.*`.
- Стан глядача — анотації `Exists`/`Subquery` у селекторах, без N+1.
- Перевірка текстури скіна (PNG, 64×64 / 64×32 → 64×64, slim за прозорими стовпцями руки, колір за найчастішим відтінком) — переходить в імпорт R6.
- Slug з транслітерацією за офіційною системою 2010 року (`core.text`).
- Сервери: SSRF-захист у два кроки; статус у кеші `server:status:{id}` 15 хв; верифікація MOTD у Celery з опитуванням; графік — власний SVG, час у `Europe/Kyiv`.
- Meilisearch: власний клієнт на httpx, один індекс `content` (`uid = {kind}-{pk}`), ранжування з популярністю; без Meilisearch — пошук за назвою в БД; оверлей — ARIA combobox.
- `/home` кешує id блоків 5 хв, картки зі станом глядача — на кожен запит; каталоги для гостей кешуються 60 с.
- Тренди — SQL (`EXTRACT(EPOCH)` + `EXP`).
- Фільтр лексики: корені й цілі слова, нормалізація цифр, латинських двійників і «р о з р і д ж е н и х» літер.
- Безпека: заголовки й CSP у `infra/nginx/snippets`; експорт і видалення акаунта (`/me/export`, `DELETE /me`).
- Prod: Gunicorn + `uvicorn-worker`; деплой — workflow на тег через ssh з `known_hosts` із секрету; бекап `pg_dump -Fc` + media, 7 днів; e2e — окремий проєкт `e2e/` з `@playwright/test`; ER — власна команда `er_diagram` (Mermaid).

## Відомі проблеми й борг (перенесено з v1)

- Swagger UI тягне ресурси з CDN jsdelivr — для суворої CSP перейти на `drf-spectacular-sidecar`.
- `notFound()` всередині потокового `<Suspense>` віддає HTTP 200 зі сторінкою 404 і `noindex`.
- CSP дозволяє `'unsafe-inline'` (Next.js без nonce); сувора політика з nonce — після захисту.
- Між перевіркою IP і з'єднанням mcstatus резолвить ім'я ще раз (вікно DNS rebinding) — для курсової прийнятно.
- Компоненти приймають `className` без `tailwind-merge`: для адаптивного приховування загортай у `div`.
- `make up-local` покладається на `host.docker.internal` (Docker Desktop).
- Пошук скіна за ніком — лише Java Edition.
- Вхід через Discord і Google не перевірено з реальними ключами.
