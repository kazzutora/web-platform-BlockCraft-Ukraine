# Дизайн-система BlockCraft

Концепція — «тихий журнал про Minecraft»: редакційний мінімалізм (великі заголовки із засічками, багато повітря, одна головна річ на екрані) з блоковими акцентами (квадрати, рамки 1 px, піксельні іконки). Не форум, не маркетплейс, не «ігровий» неон.

## Токени (`src/styles/tokens.css`)

```css
:root, [data-theme="light"] {
  --bg: #F4F1EA;          /* теплий папір */
  --surface: #FBF9F4;     /* картки, поля */
  --text: #1C1B18;
  --text-muted: #6E6A62;
  --line: #DDD8CC;        /* рамки, розділювачі */
  --accent: #4D7832;      /* зелений трави: «збережено», онлайн, фокус (≥ 4.5:1 на --bg) */
  --accent-contrast: #FFFFFF;
  --primary-bg: #1C1B18;  /* головна кнопка */
  --primary-fg: #F4F1EA;
  --danger: #B3402F;
  /* мітки розділів — лише в чипах */
  --tag-mods: #4F7A34; --tag-packs: #7E57A8; --tag-skins: #C2803A;
  --tag-servers: #2F8FA3; --tag-moments: #B3402F;
}
[data-theme="dark"] {
  --bg: #121211; --surface: #1A1A18; --text: #EDEAE3; --text-muted: #8C887F;
  --line: #2C2B28; --accent: #7FB55A; --accent-contrast: #121211;
  --primary-bg: #EDEAE3; --primary-fg: #121211; --danger: #E06A55;
}
```

Підключення в Tailwind 4 через `@theme` (`--color-bg: var(--bg)` тощо). У компонентах — лише класи токенів (`bg-bg`, `text-muted`, `border-line`), жодних hex.

## Сітка й відступи

- Контейнер `max-w-[1200px] mx-auto px-4 md:px-8`.
- Шкала відступів кратна 8 px; між секціями головної — 120–160 px, у каталогах — 64 px.
- Каталоги: сітка 2 / 3 / 4 колонки (мобільний / планшет / десктоп), проміжок 24 px.
- `border-radius: 0` скрізь, включно з аватарами й кнопками.
- Рамки 1 px `--line`. Тіней і градієнтів немає.

## Компоненти — правила

- **Button:** primary (заливка `--primary-bg`), secondary (рамка 1 px), ghost (лише текст). Висота 40 / 48 px. На екрані одна primary-кнопка.
- **Card:** квадратна обкладинка 1:1 з рамкою, під нею назва (Inter 500, 15 px) і один рядок метаданих. Іконка «Зберегти» в правому верхньому куті з'являється при наведенні (на мобільних — завжди). При наведенні обкладинка трохи збільшується (`scale 1.02`, 200 мс).
- **SaveButton:** порожній квадрат-слот → при збереженні «заповнюється» `--accent` (анімація 180 мс). Лічильник поруч опційно.
- **FilterChip:** прямокутник з рамкою; активний — заливка `--text`, текст `--bg`. Фільтри — горизонтальний рядок зі скролом на мобільних, а не бокова колонка.
- **Tabs:** капслок-мітки, активна підкреслена лінією 2 px.
- **Dialog / Sheet:** на десктопі — модалка по центру, на мобільних — шторка знизу.
- **EmptyState:** маленька ілюстрація + одна фраза + одна дія.
- **Skeleton:** прямокутники кольору `--line` з пульсацією; без спінерів на весь екран.

## Сторінки

- **Каталог:** ілюстрація розділу (≤ 160 px), H1, лічильник, рядок фільтрів, сітка, «Показати ще».
- **Об'єкт:** перший екран — медіа ліворуч (для скіна — 3D), праворуч H1, 2 рядки опису, головна кнопка, «Зберегти» й «В колекцію». Далі вкладки «Опис · Версії · Відгуки · Схоже».
- **Головна:** герой (заголовок, рядок пояснення, пошук, ілюстрація-острівець) → «Для твоєї версії» → «Скін тижня» (3D) → «Момент тижня» → «Сервери онлайн зараз» → «Нові зборки» → «Челендж тижня» → футер.

## 3D і анімації

- 3D — лише skinview3d для скінів; ліниве завантаження, fallback-PNG, повільне обертання, при `prefers-reduced-motion` — статичний кадр.
- Анімації — `motion`: поява секцій при скролі (fade + 8 px вгору, 300 мс), без паралаксу й повноекранних ефектів.

## Мобільна версія

- Шапка: логотип, лупа, меню. Нижня панель: Головна · Пошук · Додати · Обране.
- Перевіряй кожен екран на 375 px: без горизонтального скролу, зони натискання ≥ 44 px.

## Стани

Кожен екран зі запитом має стани: завантаження (skeleton), порожньо (EmptyState), помилка (фраза + «Спробувати ще»), немає доступу (пропозиція увійти).

## Перевірка перед здачею UI

- Обидві теми, 375 px і 1440 px, навігація клавіатурою, контраст ≥ 4.5:1.
- На екрані одна головна дія, тексту — мінімум, жодних hex і тіней.
