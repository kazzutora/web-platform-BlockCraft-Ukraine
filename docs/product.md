# BlockCraft Ukraine — продукт (v2)

> Ребілд, листопад 2026. Перша версія концепції — `docs/archive/v1/`.
> Цей документ відповідає на «що і навіщо». Як будувати — `docs/tech.md`.

## 1. Одним абзацом

**BlockCraft Ukraine** — україномовний навігатор по контенту Minecraft: Java Edition. Сайт не створює й не зберігає модів, збірок, скінів чи серверів — він бере їх із відкритих джерел (Modrinth, MineSkin, Mojang), підбирає під гру конкретного гравця (версія + лоадер), перевіряє сумісність і залежності, додає переклади й відгуки українською та дає поділитися готовим набором одним файлом або посиланням.

Гасло: **«Збери свій Minecraft»**. Шлях гравця: **знайти → взяти → поділитися**.

## 2. Для кого і яку проблему вирішуємо

Гравець 12–25 років, Java Edition, часто грає з друзями. Хоче моди, шейдери, сервер чи скін — і щоразу:

1. **Шукає на 4–5 англомовних сайтах.** Моди — Modrinth/CurseForge, скіни — NameMC, сервери — окремі списки, інструкції — YouTube.
2. **Ламає гру несумісністю.** Мод під іншу версію чи лоадер, забута залежність (Fabric API), два моди конфліктують, шейдер без Iris.
3. **Не може повторити сетап у друга.** «Скинь, які в тебе моди» → 20 посилань у Discord, у кожного свої версії.
4. **Не має українського контексту.** Описи й відгуки англійською, сервери без фільтра мови.

## 3. Рішення: три дії

| Розділ | Зайшов, щоб… | Взяв | Поділився |
| --- | --- | --- | --- |
| Моди, ресурспаки, шейдери, датапаки | знайти щось під свою версію | файл + усі залежності «для 1.21.1 · Fabric» або «в збірку» | відгук, переклад опису, добірка |
| Збірки | отримати готову гру «під ключ» або грати з другом однаково | `.mrpack` для лаунчера або список прямих посилань | свою збірку з реальних модів, копію чужої під іншу версію |
| Перевірка модів (`/import`) | зрозуміти, чому гра не стартує, чи можна оновитись | звіт сумісності й оновлень | «зберегти як збірку» й поділитися |
| Сервери | знайти, де пограти (українською, ванільний чи з модами) | IP + те, що потрібно для входу (версія або збірка) | відгук; власник — підтверджує свій сервер і пише опис українською |
| Скіни | новий вигляд | PNG + інструкція, як поставити | додати скін у каталог (з MineSkin чи за ніком), добірка |

Правила інтерфейсу, що випливають із цього:

- На сторінці кожного об'єкта — **одна головна кнопка «взяти»**: «Завантажити для 1.21.1 · Fabric», «Завантажити .mrpack», «Скопіювати IP», «Завантажити PNG». Поруч — «Зберегти» і «В збірку / добірку».
- **«Моя гра»** (версія + лоадер) видна в шапці завжди, і гостю теж. Усе за замовчуванням відфільтровано під неї; «показати все» — один перемикач.
- Кабінет `/me` має три блоки: **Моя гра · Взяв · Поділився**. Гравець бачить, навіщо він тут: що він уже взяв і що дав спільноті.
- Кожна картка й сторінка показує **джерело** («Modrinth ↗»). Ми — шар поверх, а не першоджерело.

## 4. Що ми НЕ робимо — і чому

- **Не приймаємо файли від гравців** (PNG скінів, моди, світи, відео). Контент живе в джерелах. Ми — шар пошуку, сумісності й спільноти; без модерації файлів, авторських ризиків і сховища.
- **Не перезаливаємо файли модів** — завантаження йде з CDN Modrinth.
- **Не вигадуємо контент.** Жодних демо-серверів, демо-модів чи фейкових відгуків на проді й у скріншотах курсової. Демо-гравці для розробки — лише поверх реальних даних і лише в dev.
- **Не парсимо сайти без відкритого API** (NameMC, Planet Minecraft, minecraftskins.com): їхні умови це забороняють, а верстка ламається.
- Не робимо форум, особисті повідомлення, маркетплейс, власний Minecraft-сервер, лайки, коментарі, рівні.
- Bedrock — лише сервери. Моди й скіни — Java Edition.

## 5. Звідки контент

| Тип | Джерело | Що беремо | Що додаємо ми |
| --- | --- | --- | --- |
| Моди, ресурспаки, шейдери, датапаки | Modrinth API v2 | метадані, версії файлів, залежності, посилання на CDN | фільтр під «Мою гру», підбір файлу й залежностей, категорії й переклади українською, відгуки |
| Готові збірки (модпаки) | Modrinth API v2 (`modpack`) | склад (`modrinth.index.json`), версія гри, лоадер | перевірка, копія під іншу версію, відгуки |
| Сервери | Modrinth API v3 (Server Projects, з березня 2026) + власники за адресою | адреса, мова, країна, режими, що потрібно для входу | власний пінг і графік онлайну, фільтр «українською», зв'язок «сервер → збірка» |
| Скіни | MineSkin API v2 (публічна галерея), Mojang API (за ніком) | текстура, модель, назва | колір і модель автоматично, 3D, добірки, «Мій скін» |
| Версії гри, лоадери | Modrinth tags, мета Fabric/Quilt/Forge/NeoForge | список релізів, версії лоадерів | — |
| Статус серверів | Server List Ping | онлайн, версія, MOTD | історія, аптайм |

Резерв після захисту: CurseForge API (потрібен ключ; світи й моди, яких немає на Modrinth), NewMinecraftServers API (сервери, без ключа).

## 6. Ключові сценарії

Кожен сценарій — це і приймальний тест етапу, і шматок демонстрації на захисті.

**С1. «Хочу шейдери, щоб не лагало»** (гість)
1. На головній обирає «Моя гра: 1.21.1 · Fabric».
2. Шейдери → фільтр «легкі» → Complementary.
3. Блок «Що встановити»: шейдер + **Iris** (додано автоматично: шейдерам на Fabric потрібен Iris) + інструкція.
4. Готово, якщо: обидва файли завантажуються з Modrinth, жодного кроку «здогадайся сам».

**С2. «Граємо з другом у модах»** (гравець)
1. Конструктор збірки: «Моя гра» за замовчуванням, додає 6 модів.
2. Залежності додаються самі з поясненням («потрібен для Sodium Extra»), конфлікт підсвічено з причиною.
3. Публікує або «лише за посиланням», кидає посилання другові.
4. Друг без акаунта натискає «Завантажити .mrpack» → імпорт у Modrinth App / Prism Launcher → гра стартує.

**С3. «Чи готові мої моди до нової версії?»** (гість → гравець)
1. `/import`: перетягує папку `mods` (браузер рахує хеші; файли нікуди не відправляються).
2. Звіт: що впізнано, що невідомо, «схоже, це 1.21.1 · Fabric», що можна оновити, що ще не портовано на 26.1.
3. «Зберегти як збірку» (тут потрібен вхід) → «Зробити копію під 26.1» → видно, що випаде.

**С4. «Де пограти українською»** (гість)
1. Сервери → мова «українська», «онлайн зараз».
2. Сторінка сервера: онлайн, графік, **«Щоб зайти: версія 1.21.1» або «Щоб зайти: збірка X»** з кнопкою «Взяти збірку».
3. «Скопіювати IP».

**С5. «Новий скін»** (гість)
1. Скіни → колір «зелений», модель «тонка».
2. 3D-перегляд → «Завантажити PNG» + «Як поставити».
3. Або «Скін за ніком» → бачить скін друга.

**С6. «Я власник сервера»** (гравець)
1. «Поділитися → Мій сервер» → адреса → сервер мусить відповісти на пінг.
2. Отримує код, додає в MOTD → «Перевірено».
3. Пише опис українською, вказує Discord і збірку для входу. Якщо сервер уже імпортовано з Modrinth — той самий потік робить гравця його власником.

**С7. «Поділитися знанням»** (гравець)
1. На сторінці мода: «Опису українською ще немає — запропонуй переклад».
2. Модератор схвалює → опис показується з підписом «переклав @нік», автор отримує сповіщення.
3. Відгук зі зірками: «на слабкому ноутбуці дає +40 FPS».

2. «Популярне для 1.21.1 · Fabric» — моди, сумісні з «Моєю грою».

## 10. Тема курсової

**Тема:** «Веб-платформа для ігрової спільноти Minecraft "BlockCraft Ukraine"».
Уточнення у вступі: платформа агрегує ігровий контент з відкритих API й автоматизує підбір сумісних модифікацій та формування збірок.

**Мета:** підвищити доступність ігрового контенту Minecraft для україномовних гравців шляхом створення веб-платформи, що агрегує контент із відкритих джерел, автоматично підбирає сумісні версії й залежності та дає спільноті формувати й поширювати збірки.

**Об'єкт:** процес пошуку, підбору й поширення ігрового контенту Minecraft у спільноті гравців.
**Предмет:** методи й програмні засоби агрегації даних із зовнішніх REST API, розв'язання залежностей модифікацій і побудови веб-застосунку спільноти.

**Задачі:**
1. Проаналізувати предметну область і аналоги, сформулювати вимоги.
2. Спроєктувати архітектуру (клієнт-серверна, SSR, фонові задачі) і модель даних.
3. Реалізувати інтеграцію з джерелами (Modrinth v2/v3, MineSkin, Mojang, Server List Ping) з інкрементною синхронізацією й журналом.
4. Розробити алгоритм підбору версій і розв'язання залежностей та експорт у формат `.mrpack`.
5. Реалізувати повнотекстовий пошук з підтримкою українських запитів.
6. Реалізувати функції спільноти: збірки, добірки, відгуки, переклади, модерацію.
7. Розробити адаптивний інтерфейс.
8. Протестувати (модульні, інтеграційні, e2e) і розгорнути систему.

**Аналоги:**

| Аналог | Що робить добре | Чого бракує українському гравцю |
| --- | --- | --- |
| Modrinth (сайт) | відкритий каталог, API, фільтри версій | англійською; сумісність набору перевіряє лише десктоп-застосунок; немає українських описів і відгуків |
| CurseForge | найбільший каталог модів | закритий API з ключем, частину файлів заборонено віддавати стороннім; реклама |
| NameMC | скіни й профілі гравців | лише скіни; немає відкритого API |
| Prism Launcher, ATLauncher | встановлення збірок | десктоп; немає спільноти й пошуку серверів |
| Списки серверів | онлайн, голосування | немає фільтра мови; не пов'язані з модами, потрібними для входу |

Ніша BlockCraft: один україномовний веб-інтерфейс, що поєднує всі типи контенту, перевіряє сумісність набору ще до завантаження й дає поділитися збіркою посиланням.

**Структура пояснювальної записки → артефакти з репозиторію:**
1. Аналіз предметної області й аналогів — цей документ, розділи 2, 5, 10.
2. Проєктування — use case, ER, компоненти, OpenAPI (`docs/coursework/`).
3. Реалізація — інтеграції й синхронізація (`docs/sources.md`, діаграма послідовності), двигун сумісності (`docs/coursework/compat.md`), пошук, інтерфейс.
4. Тестування — звіт покриття, e2e-сценарії С1–С5.
5. Розгортання — `docs/deploy.md`.

**Демонстрація на захисті (~7 хв):**
1. Гість обирає «1.21.1 · Fabric» — головна й каталог перебудовуються.
2. Шейдер → «Що встановити»: шейдер + Iris.
3. Конструктор: 5 модів, автозалежності, конфлікт → виправлення → `.mrpack` → імпорт у Prism Launcher (запасний варіант — заздалегідь записане відео).
4. `/import`: папка `mods` → «що випаде при переході на 26.1».
5. Сервер українською → «Щоб зайти: збірка X» → IP.
6. Адмінка: журнал синхронізацій джерел, модерація перекладу.
7. Swagger, тести, CI.

## 11. Глосарій

- **Лоадер** — Fabric, Forge, NeoForge, Quilt: програма, що завантажує моди. Мод під один лоадер зазвичай не працює в іншому.
- **Моя гра** — пара «версія гри + лоадер», під яку сайт фільтрує все.
- **Залежність** — інший мод, без якого мод не запуститься (required), може доповнити (optional), не сумісний (incompatible).
- **Збірка** — набір модів, ресурспаків, шейдерів і датапаків під одну «Мою гру». Готові збірки — модпаки з Modrinth; збірки спільноти — складені гравцями з реального контенту.
- **`.mrpack`** — відкритий формат збірки Modrinth: список файлів із хешами й посиланнями на CDN; його відкривають Modrinth App, Prism Launcher, ATLauncher.
- **Добірка** — тематичний список будь-чого (моди, збірки, сервери, скіни) без перевірки сумісності.
- **Джерело** — зовнішній сервіс, звідки прийшов об'єкт (Modrinth, MineSkin, Mojang, власник сервера).
